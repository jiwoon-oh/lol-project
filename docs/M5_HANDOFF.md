## 1. 사용 장면

T1 전력분석관이 드래프트를 보면서 상대(예: 한화) 밴·픽을 입력 → 화면에
1. **T1 다음 차례 추천** (밴이면 밴 후보, 픽이면 픽 후보) 상위 5 + 근거
2. **상대 다음 선택 예측** 상위 5 + 확률
3. 지금까지 조합의 성격·예상 승률 변화

입력: 진영(블루/레드), First Selection(선픽/후픽), 세트 번호, 이번 매치 앞 세트에 쓴 챔피언(피어리스), 앞 세트 승패, 양 팀 라인업, 지금까지의 밴·픽 순서

## 3. 추천 점수 설계 (핵심)

M4 의 점수는 "고를 확률" 이고, 추천은 "이길 가치" 입니다. **둘을 섞지 말고 같은 단위(기대 승률 변화)로 바꿔 더합니다** (설계 점검 A4).

### 3-1. 먼저 할 일: M4 점수를 확률로 보정
- 지금 M4 는 순위(top-k)만 검증됨. 추천에 쓰려면 **확률**이 필요 → 단계마다 소프트맥스 `p = exp(s/τ) / Σ exp(s/τ)` 의 온도 τ 를 **리허설 세트(LCK 26.14 · 26.15 · RTM)** 로 맞춤 (로그 손실 최소). 밴 앙상블 점수도 같은 방식
- **플레이오프(08-26~)로 τ 나 가중치를 맞추면 안 됨** (최종 검증을 이미 한 번 썼음)
- **완료 (2026-11-08)**: `src/pipeline/m5_calibrate.py` → `data/processed/2026/m5/calibration.json` (`m4/final/` 은 그대로) (페이즈별 τ 1밴 0.84 · 1픽 0.84 · 2밴 0.93 · 2픽 0.98, ε 0). 리허설 세트마다 그 세트 전 자료로 다시 학습한 학습 밖 점수로 맞춤. 30% 이상 확률은 아직 조금 과신. 기록은 `docs/PIPELINE.md` 7-7 끝. 가상 드래프트 시험판은 `src/pipeline/m5_sim.py`

### 3-2. 우리 픽 추천
```
가치(c) = Δ승률(우리 조합에 c 추가)            ← M1 조합 성격(+상호작용) + M2 챔피언 단독
        − Σ_d P(상대가 다음에 d) × 손해(d | 우리에 c 있음)   ← 상대 응수 위험 (M4 상대 예측 × 상성)
        + 숙련 가산(우리 선수 c 숙련, 승리 효과가 확인될 때만)
```
- Δ승률: 남은 자리는 M4 가 예측한 우리·상대 픽 확률로 채운 평균 조합으로 계산 (미완성 조합 문제)
- 상대 응수 위험: M4 픽 모델로 "c 를 뽑은 뒤 상대 다음 픽" 확률을 다시 계산 → 1수 앞보기
- 근거 칸: "맞라인 상성 15분 골드 ±N (판수)", "듀오 골드 +N", "시너지 22쌍 해당", "프로가 우연의 x배로 묶음"
- **이길 가치 표 (2026-11-08)**: `data/processed/2026/m5/m5_value_champion.csv` 의 `value_pro` (대회 %p = k × 10·15·20·25분 경로. 2026-11-08 M1 가중치 학습에서 w ≈ 0 → M1 성격 몫은 뺌, `m5_value_w.py`, 예전 E-C 표는 `m5_value_champion_ec.csv`). 초반·후반 몫 칸도 있음 → 화면 근거 "초반 +x · 후반 +y". 만든 방법·리허설 비교는 `docs/PIPELINE.md` 7-7 끝 "M5 2단계". 아직 챔피언 하나씩 값 (조합 단위 계산은 다음)

### 3-3. 우리 밴 추천
```
밴 가치(c) = P(상대가 c 를 고름) × [그때 우리 승률 감소] + P(상대가 c 를 고름) × α(상대 선수 주력·시그니처)
```
- P(상대가 c) = M4 를 **상대 팀 입장**으로 돌린 픽 확률 (상대 라인업·습관·시리즈 정보 포함)
- 그때 승률 감소 = M1 + M2 로 "상대 조합에 c 추가" 의 Δ승률
- 피어리스: 밴은 다음 세트에도 다시 걸 수 있음 (앞 세트 밴 반복이 많음 — M4 시리즈 특징이 이미 반영)

### 3-4. 피어리스 시리즈 관리 (선택)
- 우리가 지금 c 를 쓰면 남은 세트에서 c 를 못 씀 → 남은 세트 수와 선수 풀 깊이로 "아껴 둘 가치" 를 빼는 항
- M4 에서는 이 신호가 예측에 안 잡혔음 (P4 효과 없음). 추천에서는 분석관이 켜고 끌 수 있는 옵션으로

### 3-5. 두 장 동시 픽 (B2·B3, R4·R5)
- 쌍 (c1, c2) 추천: 가치(c1) + 가치(c2 | c1) + 시너지 근거. 후보는 각자 상위 10 의 조합으로 좁혀 계산

### 3-6. 드래프트 시뮬레이터 구조 (추천 방향, 2026-11-07 추가)

M4 를 "양 팀이 실제로 어떻게 고르는지" 흉내 내는 엔진으로 쓰고, 그 위에 "어느 쪽이 이기는지" 계산기를 얹는 형태.

```
[드래프트 상태] 진영 · 선픽 · 세트 번호 · 피어리스로 쓴 챔피언 · 앞 세트 밴픽·승패 · 지금까지의 밴픽 · 라인업
      │
      ├─ ① 상대 행동 예측 (M4, 상대 팀 입장)  → "상대 다음 픽: 애쉬 31% · 세라핀 18% · 자야 9% …"
      │
      ├─ ② 우리 후보 c 평가
      │      a. 우리 조합 가치  : c 를 넣었을 때 우리 조합 승률 변화 (M1 성격 + M2 챔피언 단독)
      │      b. 뺏기 가치       : P(상대가 c 를 원함) × 상대가 c 를 가졌을 때 우리 손해
      │      c. 응수 위험       : c 를 뽑은 뒤 상대 다음 픽 확률(M4 재계산) × 그 응수의 손해
      │      d. 피어리스 비용   : 지금 c 를 쓰면 남은 세트에서 양 팀 모두 못 씀 (옵션, 상대 주력을 시리즈에서 지우는 효과도)
      │
      ├─ ③ 앞보기 시뮬레이션 : 상위 후보 몇 개에 대해 남은 드래프트를 M4(양 팀)로 수백 번 굴려 끝까지 갔을 때 예상 승률 분포
      │
      └─ ④ 추천 + 근거       : "c 추천: 예상 +3.1%p (뺏기 +1.4 · 조합 +1.2 · 응수 위험 −0.5)" + 상성·듀오 골드·시너지·프로 동시 픽 lift
```

- **상대가 이미 한 밴·픽은 입력** (맞힐 필요 없음). 모델은 "그 다음" 만 계산
- **M4 는 양쪽에 씀**: 상대 팀 입장 = 상대 예측, T1 입장 = "평소 하던 대로라면" (시뮬레이션에서 남은 차례 채우기용, 추천 점수 자체는 아님)

**예시** — 3세트, 상대가 블루 1픽(예: 바이), 아직 바텀 없음, 상대가 애쉬 + 세라핀을 좋아함
1. 상대 예측: 다음 두 장으로 "애쉬 28% · 세라핀 21% · 루시안 12% …" — 상대의 동시 픽 lift(애쉬 + 세라핀 우연의 약 8배), 상대 선수 주력, 1·2세트에 쓴 챔피언 제외(피어리스), 앞 세트 밴 반복이 이미 반영
2. 우리 R1·R2 두 장 평가: 애쉬를 가져오면 상대 조합이 깨짐(뺏기) + 우리 원딜 숙련 + 바이 응수(정글 상성) + 우리 조합 성격 → 쌍으로 추천 (예: 애쉬 + 우리 정글)
3. 응수 위험: 우리가 애쉬를 가져간 뒤 상대가 무엇으로 받을지 M4 로 다시 계산
4. 피어리스: 우리가 애쉬를 쓰면 4·5세트에 양 팀 모두 못 씀 → 상대 주력을 시리즈에서 지우는 효과까지
5. 화면: "애쉬 (뺏기) — 상대가 고를 확률 28%, 애쉬 + 세라핀 차단, 우리 원딜 숙련 대회 6판, 예상 +2.4%p"

**조심할 점**

| 문제 | 내용 | 대응 |
|---|---|---|
| 이길 가치가 약함 | 조합의 승률 몫이 작고(M1), 쌍 시너지·카운터는 승패로 검증 안 됨 | 예상 승률은 **참고치**, 화면 중심은 상대 확률 + 근거. 상성·듀오는 "15분 골드 ±N" 으로 |
| 확률 보정 | M4 는 순위(top-k)만 검증됨 | 리허설 세트로 온도 τ 를 먼저 맞춤 (3-1) |
| 계산량 | 후보 130개 × 남은 차례 전부는 무거움 | 차례마다 M4 상위 10~15개로 좁히고, 앞보기 1~2수 + 몬테카를로 수백 번 (몇 초) |
| T1 습관 ≠ 정답 | M4 로 T1 을 흉내 내면 평소 픽 쪽으로 쏠림 | 추천 점수는 조합·뺏기·응수·피어리스로 따로 계산, T1 습관은 참고 칸 |
| 검증 | 플레이오프는 이미 한 번 씀 | 리허설 세트(26.14 · 26.15 · RTM) 드래프트를 단계별로 재생하며 조정 |

## 4. 이미 알게 된 것 (설계에 반영할 점)

1. **프로 픽은 "이기는 픽" 보다 메타·숙련·상대 반응으로 설명됨** — 이길 가치 특징은 M4 예측력을 거의 안 늘렸음. 그래서 추천(이길 가치)과 예측(고를 확률)을 분리해야 함
2. **쌍 효과(시너지·카운터)는 승패로는 검증 안 됨** — 15분 골드에서만 보임. 승률 계산에 넣지 말고 근거로만 표시. 넣고 싶으면 골드 → 승률 환산(`m3_gold_to_win.csv`)을 쓰되 "참고" 로 표시
3. **같은 시리즈 앞 세트 정보가 크다** — 앞 세트 밴 반복 (2세트 이상 밴의 39.5%, 1밴 페이즈 56%). 입력에 앞 세트 밴·픽·승패를 꼭 받을 것
4. **강팀(Gen.G·한화)은 예측이 어려움** (픽 top5 54~58%) — 화면에 확률을 보여 주고, 상위 5 밖 선택도 흔하다는 걸 표시
5. **2밴 페이즈는 반응형** (상대 빈 포지션, 우리 픽 응수 막기, 조합 완성 막기) — 밴 추천 근거에 이 항목들을 보여 주면 납득이 쉬움
6. **26.16 은 LCK 경기가 적었던 패치** — 같은 패치의 다른 리그(LEC·LCS 가 4~7일 먼저 시작)가 메타 신호 (M4 P1)

| 매 세트 사이 | 앞 세트 밴·픽·승패를 시리즈 특징에 반영 (같은 날 다른 매치는 안 씀) |
| 드래프트 중 | 단계마다 후보·빈 포지션·이미 밴·픽 갱신 → M4 점수 → 확률 → 추천 점수 |
| 패치가 바뀌면 | P1 (같은 패치 다른 리그 등장률·패치노트 버프/너프) 갱신 |

- 모델 다시 학습은 시즌 중간이 아니라 일정한 때(예: 스플릿 사이)에만. 다시 학습하면 리허설로 다시 검증

---

## 6. M5 평가 방법

| 지표 | 계산 | 비고 |
|---|---|---|
| 상대 예측 | M4 와 같음 (top-k) | 이미 검증 |
| 확률 보정 | 리허설에서 로그 손실·보정 곡선 | τ 맞춘 뒤 |
| 추천 조합의 예상 승률 | 추천대로 뽑았을 때 M1 + M2 예상 승률 vs 실제 T1 조합 | 참고 (실제 승패로 판정하면 인과가 아님) |
| T1 실제 픽과 일치율 | 추천 상위 5 안에 T1 실제 픽 | **참고만** (높아도 "하던 걸 따라 함" 일 수 있음) |
| 분석관 평가 | 근거 표시가 납득되는지 | 정성 |

- **조정은 리허설 세트로만**. 플레이오프 결과를 보고 가중치를 바꾸지 말 것

---

## 7. 구현 순서 (제안)

1. M4 점수 → 확률 보정 (τ, 리허설) — 반나절
2. `m4_validate.py` 의 특징 계산을 "드래프트 상태를 입력으로 받는 함수" 로 감싸기 (`build_rows_for` 는 기록에서 상태를 읽음 → 입력에서 읽게) — 1일
3. 이길 가치 계산기: 부분 조합 + 후보 → M1 + M2 Δ승률 (남은 자리는 M4 확률로 채움) — 1일
4. 픽·밴 추천 점수 (3-2, 3-3) + 근거 칸 — 1일
5. 화면 (대시보드 쪽 틀과 맞춤) + 리허설 재생으로 점검 — 1~2일
